# סטודיו סרטונים

עורך סרטונים שרץ כולו בדפדפן: מעלים סרטון שמדברים בו (או הקלטה), בירולים וזוגות לפני/אחרי, בוחרים אורך וסגנון, ומקבלים כמה גרסאות MP4 מוכנות.

- **בלי שרת ובלי עלות:** התמלול (מודל עברית של ivrit-ai, `whisper-large-v3-turbo-onnx`, דרך transformers.js), החיתוך, המוזיקה והרינדור קורים במחשב של המשתמש. האתר עצמו סטטי (GitHub Pages).
- **גרסאות:** מדבר + בירולים, פתיחה ואז בירולים, חלון קטן, חצי מסך, רק מדבר, קול על בירולים, לפני/אחרי על הביט, מונטאז׳ על הביט.
- **מוזיקה:** נוצרת בדפדפן (`js/music.js`) בלי זכויות יוצרים, עם BPM ידוע כך שהחיתוכים נופלים על הביט. אפשר גם שיר משלך.

## קבצים
- `js/app.js` — הממשק והזרימה
- `js/engine.js` — התוכנית (מה על המסך בכל רגע) והנגן שמצייר על canvas ומקליט
- `js/audio.js` — פענוח אודיו, זיהוי דיבור, בחירת משפטים לפי אורך
- `js/asr-worker.js` — התמלול ב-Web Worker
- `js/music.js` — מחולל המוזיקה וזיהוי ביט לשיר שהועלה

## בדיקה מקומית
`python -m http.server 5173` ואז `http://localhost:5173/?demo=1` טוען קבצים מ-`demo/manifest.json` (התיקייה לא בריפו).
